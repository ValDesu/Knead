# Knead

Squash, stretch, twist and bend any mesh with a lattice box. Add a **Knead Box** to an object, drag the
handles in the Scene view, save poses, and tween with one line: `box.Bounce(KneadTween.Squish)` or
`box.TweenToPose("Happy")`. Add a **Knead Physics Box** to make it react to collisions like jelly, rubber,
cardboard or clay.

Requires Unity 6. Meshes need Read/Write enabled to deform in builds (the inspector fixes it in one click).

Full documentation: see the repository README.
